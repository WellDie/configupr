Эмулятор командной строки (Shell Emulator)

Эмулятор представляет собой приложение с графическим интерфейсом (GUI), которое поддерживает базовые команды консоли и работает с виртуальной файловой системой (VFS) в оперативной памяти. 
Любые изменения файлов и папок внутри эмулятора не затрагивают реальный жесткий диск, пока не будет вызвана команда явного сохранения.

Основной функционал
- GUI: Реализован на базе стандартной библиотеки Java Swing.
- Работа с VFS: Загрузка структуры реальных папок в память, модификация в памяти и выгрузка обратно на диск.
- Стартовые скрипты: Поддержка выполнения заранее заготовленных файлов со скриптами при запуске.
- Поддерживаемые команды:
  - `ls` — вывод содержимого текущей директории.
  - `cd <путь>` — переход по директориям.
  - `uniq <файл>` — вывод содержимого файла.
  - `rm <имя>` — удаление файла или папки из VFS.
  - `clear` — очистка экрана терминала.
  - `exit` — выход из эмулятора.
  - `vfs-load <путь>` — загрузка новой виртуальной файловой системы с диска.
  - `vfs-save <путь>` — сохранение текущего состояния VFS на жесткий диск.
