# Визуализатор графа зависимостей (Вариант 22)

Инструмент командной строки для построения и визуализации графа зависимостей пакетов менеджера Cargo (Rust).

## Описание
Приложение анализирует прямые и транзитивные зависимости заданного пакета и генерирует визуальное представление графа в формате SVG с использованием PlantUML. Реализован алгоритм обхода в ширину (BFS) без использования рекурсии.

## Параметры конфигурации (CLI)
- `--pkg <имя>` — Имя анализируемого пакета.
- `--repo <путь>` — URL-адрес репозитория или путь к файлу тестового репозитория.
- `--out <файл>` — Имя сгенерированного файла с изображением графа.
- `--test` — Режим работы с локальным тестовым репозиторием.

## Сборка и запуск тестов
Для компиляции исходного кода и демонстрации работы парсера (включая обработку ошибочного ввода) используйте скрипты:
- **Windows:** `run.bat`
- **Linux/Mac:** `./run.sh` (предварительно `chmod +x run.sh`)
